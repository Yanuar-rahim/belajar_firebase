Pengertian Firebase

Firebase adalah platform pengembangan aplikasi dari Google yang menyediakan berbagai layanan backend (bagian belakang aplikasi) siap pakai. Layanan ini membantu pengembang membangun aplikasi Android, iOS, dan web tanpa harus menyiapkan seluruh server dan infrastruktur backend sendiri dari awal.

Dengan Firebase, aplikasi dapat menyimpan data, mengelola akun pengguna, mengirim notifikasi, menyimpan file, serta memantau penggunaan aplikasi. Firebase menyediakan SDK (Software Development Kit) agar aplikasi dapat berkomunikasi dengan layanan tersebut.

Contoh sederhana

Pada aplikasi Data Mahasiswa, data nama, NIM, dan program studi dapat disimpan di Cloud Firestore. Perangkat lain dapat mengambil data tersebut selama terhubung ke internet dan aturan akses database mengizinkannya.

Mengapa menggunakan Firebase?

  • Mempercepat pengembangan karena beberapa layanan backend sudah disediakan.
  • Mendukung penyimpanan data berbasis cloud.
  • Menyediakan SDK dan dokumentasi untuk berbagai platform.
  • Mendukung sinkronisasi data, termasuk pembaruan real-time pada layanan yang sesuai.
  • Menyediakan autentikasi dan aturan keamanan untuk mengatur akses pengguna.
  • Dapat digunakan untuk proyek pembelajaran hingga aplikasi yang lebih besar, dengan memperhatikan kuota dan biaya.

Pengertian Cloud Firestore

Cloud Firestore adalah layanan database NoSQL berbasis cloud dari Firebase. Firestore menyimpan data dalam bentuk dokumen (document) yang dikelompokkan ke dalam koleksi (collection). Setiap dokumen berisi pasangan field dan value, misalnya field nama bernilai “Yanuar”.

Disebut NoSQL karena Firestore tidak memakai model tabel-relasi seperti database relasional pada umumnya. Dokumen dapat berisi berbagai tipe data: string, angka, boolean, tanggal/waktu, array, map, dan tipe lain yang didukung.

Karakteristik

  • Berbasis cloud: data disimpan di infrastruktur Google dan diakses lewat SDK atau API sesuai aturan akses.
  • Berorientasi dokumen: data disimpan dalam dokumen yang memiliki field dan value.
  • Terorganisasi dalam koleksi: dokumen dikelompokkan ke dalam collection.
  • Mendukung query untuk mencari atau menyaring dokumen.
  • Mendukung listener real-time untuk menerima pemberitahuan saat data yang didengarkan berubah.
  • Memiliki Security Rules untuk menentukan siapa yang boleh membaca atau menulis data.

Contoh penggunaan

Pada aplikasi data mahasiswa, satu collection diberi nama mahasiswa. Di dalamnya ada satu dokumen untuk setiap mahasiswa, berisi nama, NIM, dan program studi. 

mahasiswa (collection)
|
|-- M001 (document)
|   |-- nama: "Yanuar"
|   |-- nim: "123456"
|   |-- prodi: "Teknik Informatika"
|
|-- M002 (document)
    |-- nama: "Andi"
    |-- nim: "123457"
    |-- prodi: "Sistem Informasi"

Firebase Console

Firebase Console adalah antarmuka berbasis web untuk membuat dan mengelola proyek Firebase. Di sini pengembang mengaktifkan layanan, mendaftarkan aplikasi, melihat data Firestore, dan mengatur aturan keamanan.

Alamat: https://console.firebase.google.com/

Membuat proyek

  1. Buka Firebase Console dan masuk dengan akun Google.
  2. Pilih Add project atau Tambahkan proyek.
  3. Masukkan nama proyek dan ikuti petunjuk.
  4. Pilih layanan yang ingin digunakan, misalnya Cloud Firestore atau Authentication.
  5. Daftarkan aplikasi Android jika proyek akan dihubungkan dengan Android Studio.

CRUD adalah singkatan dari Create, Read, Update, Delete, empat operasi dasar pengelolaan data pada aplikasi.

Perbandingan dengan database SQL

Database SQL (misalnya MySQL atau SQLite) menyimpan data dalam tabel yang terdiri dari baris dan kolom. Cloud Firestore menyimpan data dalam collection yang berisi dokumen. Konsepnya berpadanan seperti berikut.

Database SQL Cloud Firestore
Table Collection
Row (baris) Document
Column (kolom) Field
Primary key Document ID

Berikut operasi CRUD yang sama pada data mahasiswa M001, ditulis dalam SQL dan dalam Firestore (Java).

Operasi SQL Cloud Firestore (Java)
Create INSERT INTO mahasiswa (id, nama, nim, prodi) VALUES ('M001', 'Yanuar', '123456', 'Teknik Informatika'); db.collection("mahasiswa").document("M001").set(mahasiswa);
Read SELECT * FROM mahasiswa WHERE id = 'M001'; db.collection("mahasiswa").document("M001").get();
Update UPDATE mahasiswa SET nama = 'Andi' WHERE id = 'M001'; db.collection("mahasiswa").document("M001").update("nama", "Andi");
Delete DELETE FROM mahasiswa WHERE id = 'M001'; db.collection("mahasiswa").document("M001").delete();

Perbedaan yang perlu diperhatikan

Aspek Database SQL Cloud Firestore
Skema Kolom dan tipe data ditentukan lebih dulu saat tabel dibuat. Tidak ada tabel dengan kolom tetap. Setiap dokumen menyimpan field-nya sendiri.
Cara menulis perintah Bahasa query SQL berupa teks. Pemanggilan method pada SDK, seperti set(), get(), update(), dan delete().
Hasil operasi Hasil dikembalikan langsung oleh database yang dipanggil. Operasi dijalankan lewat jaringan, hasilnya diterima lewat listener berhasil atau gagal.
Data yang sudah ada INSERT dengan primary key yang sama akan ditolak. set() pada ID yang sama menimpa dokumen lama.
Hak akses Diatur lewat pengguna dan hak akses database. Diatur lewat Firebase Security Rules.

Bagian perbandingan SQL ini tambahan di luar dokumen materi asli, dan contoh SQL-nya bersifat umum (dapat sedikit berbeda antar produk database).

Potongan kode di atas adalah contoh inti. Sesuaikan import, nama package, komponen tampilan, dan penanganan hasil dengan struktur aplikasi Anda.

Keamanan database dan Firebase Rules

Firebase Security Rules adalah aturan yang menentukan permintaan apa saja yang boleh membaca atau menulis data. Aplikasi yang terhubung ke Firebase tidak boleh otomatis diberi akses penuh ke seluruh database.

Untuk aplikasi yang punya akun pengguna, aturan sebaiknya memeriksa identitas pengguna dan membatasi akses sesuai kepemilikan atau peran.

Hindari aturan terbuka yang mengizinkan semua orang membaca dan menulis data, terutama pada aplikasi yang dipakai secara nyata.

Dokumentasi: firebase.google.com/docs/firestore/security/get-started

Rangkuman

  • Firebase adalah platform pengembangan aplikasi yang menyediakan layanan backend dari Google.
  • Cloud Firestore adalah database NoSQL berbasis dokumen yang memakai collection dan document.
  • Dokumen berisi field dan value yang menyimpan informasi.
  • Firebase Console dipakai untuk mengelola proyek dan layanan Firebase.
  • Firebase SDK memungkinkan aplikasi Android berkomunikasi dengan Firebase.
  • CRUD terdiri dari Create, Read, Update, dan Delete.
  • Firebase Security Rules harus dikonfigurasi agar akses database sesuai kebutuhan aplikasi.
